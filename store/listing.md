# Google Play 스토어 등록정보 (초안)

## 앱 이름 (30자 이내)
날래 - 오늘 어디 갈까

## 간단한 설명 (80자 이내)
오늘 어디 갈까, 날래! 가까운 데이트 코스를 고르고 맛집·놀거리를 저장해요. 동네 소식과 생활정보도 함께.

## 자세한 설명 (4,000자 이내)
동네 소식, 날래 왔다오.
날래는 전국 곳곳의 공공 소식을 지도 위에 보여주는 앱입니다.

■ 지도가 반짝이면, 그 동네에 소식이 왔다는 뜻
긴급재난문자, 기상특보, 지진정보가 들어오면 해당 시·군·구(지진은 진앙)가 지도에서 반짝입니다. 앱을 열면 최근 1시간 소식이 빠르게 재생되어 지금 어디서 무슨 일이 있는지 한눈에 볼 수 있어요.

■ 동네 탐험
· 날씨: 시·군·구별 현재 기온과 비·눈, 오늘·내일 최저·최고 기온과 강수확률
· 주유소: 선택 지점 5·10·15km 반경 안에서 거리순·최저가순 조회
· 주차장: 전국 공영·민영 주차장 위치·요금·운영시간, 서울 시영주차장은 지금 주차 대수
· 축제: 진행 중이거나 곧 열리는 지역 축제
· 식품안심업소: 식약처가 위생 상태를 확인해 지정한 음식점 목록
좌표가 있는 곳은 '길찾기'를 누르면 카카오맵으로 바로 이어집니다.

■ 내 주변 소식만 모아 보기
'내 주변'을 누르면 내가 있는 시·군·구와 맞닿은 지역의 소식만 모아 보여줍니다. 위치는 기기 안에서만 쓰고 서버로 보내지 않아요. 위치 권한 없이도 지도에서 동네를 눌러 같은 기능을 쓸 수 있습니다.

■ 분류별로 골라 보기
재난, 기상, 사건, 교통, 개발, 행정, 생활 중 원하는 분류만 골라 볼 수 있어요.

■ 회원가입·광고 없음
가입이나 로그인이 필요 없고 광고가 없습니다. 저장과 개인 기록은 이 기기에 보관해요. 주유소 반경 조회 시 선택 좌표를 조회 서버로 전달하며, 메일 제보 시 메일 주소와 작성 내용을 처리합니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있어요.

■ 정보 출처
· 긴급재난문자: 행정안전부 재난안전데이터공유플랫폼
· 기상특보·지진정보: 기상청 API허브
· 현재 기온·단기예보: 기상청 (공공데이터포털)

· 지역 축제: 전국문화축제표준데이터 (공공데이터포털)
· 주유소 가격: 오피넷 (한국석유공사)
· 주차장: 전국주차장정보표준데이터 (공공데이터포털), 서울시 시영주차장 실시간 정보 (서울열린데이터광장)

## 데이터 보안 양식 (Data safety) — 제출 전 재검토 필요
- 과거의 ‘수집 없음·위치가 기기 밖으로 나가지 않음’ 답변은 현재 기능과 맞지 않으므로 사용하지 않는다.
- 일반 코스·소식 주변 검색과 저장/개인 메모는 기기 안 처리. 주유소 반경 조회는 사용자가 선택한 좌표·유종·반경을 날래 서버와 오피넷에 전달한다.
- 메일 제보는 사용자가 메일 앱에서 직접 전송하며 운영자는 메일 주소·제보 내용을 처리한다. 개인정보처리방침과 실제 보관·삭제 절차를 일치시킨다.
- Google은 기기 밖으로 보내 일시 처리하는 정보도 양식 응답에 포함하도록 안내한다. 일시 처리 요건 충족 여부와 수집/공유 구분은 실제 서버 및 외부 메일 앱 흐름을 확인해 최종 작성한다. 현재 문서는 제출 완료를 뜻하지 않는다.
- 공식 기준: https://support.google.com/googleplay/android-developer/answer/10787469
- 전송은 HTTPS, 제보 삭제 요청은 nallae.app@gmail.com. 앱의 개인 기록은 사용자가 기록 삭제 또는 앱 데이터 삭제로 제거한다.
