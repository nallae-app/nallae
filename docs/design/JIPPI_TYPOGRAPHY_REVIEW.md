# 지삐 브랜드 타이포 교차 검토 — 2026-11-04

사용자가 확정한 GPT 원본 그림과 문구를 보존하고 일반 UI 글꼴·소개 배너만 교정했다.

- 실제 GPT 디자인 대화: https://chatgpt.com/c/6adc7635-6128-83e8-998f-31105490b2ee
- 실제 Claude 독립 대화: https://claude.ai/chat/cc70d37f-b47e-4af6-81fd-2943f5a616ca
- 두 검토자 모두 이전 배너/라이트/다크 3장과 수정 배너 2장/390px 모바일 1장을 실제 첨부로 검토했다. 실기기 사용성 시험은 아니다.

## 반론과 결정

GPT는 Wanted Sans를 추천했다. Claude는 기존 Pretendard 통일을 추천하고 혼용 질감·슬로건의 로고 압도를 우려했다. Codex는 기존 본문과 목록의 변동을 줄이기 위해 브랜드 제목·슬로건에만 Wanted Sans 가변 파일을 자체 호스팅했다. 수정 실물을 본 두 검토자는 혼용·로고 압도 우려가 크지 않다고 판단했다. 750 고정 대신 700을 채택했다.

질문은 모바일 16px/500, 슬로건은 24px/700/행간 1.3. 배너 질문 22px/500, 슬로건 50px/700. ‘지삐지기’에서 ‘지삐’ 두 글자만 강조한다. 로고 내부 글자는 원본 픽셀 그대로다. 크림·네이비 배너는 동일 구조이며 폰 목업 전체를 500px 안에 넣었다.

Claude가 지적한 ‘보여드/려요’ 줄바꿈은 keep-all로 수정하고 실제 화면을 다시 캡처했다. 헤더 뒤 지도·캐릭터 중첩은 브랜드 영역 배경으로 막았다. GPT가 지적한 지도 노출 부족은 정보 목록을 넓게 보려는 기존 사용자 요청을 유지하는 판단이며 시트를 접으면 지도를 볼 수 있다. 네이비 목업은 작은 노출에서 크림보다 콘텐츠 판독성이 낮을 수 있다.

Wanted Sans 공식 원본: https://github.com/wanteddev/wanted-sans (revision 02c9b822349c188ada95f9e2d90c2ed18f853235). OFL 1.1과 AUTHORS를 배포 파일 옆에 보존한다. 강조색 대비는 크림 5.92:1, 네이비 9.79:1, 다크 카드 7.48:1.

## 재생성

`node scripts/build-jippi-assets.mjs` → `node scripts/build-icons.mjs`. 배너는 `node scripts/build-feature.mjs`로 `store/feature.html` 생성 후 브라우저에서 지정 글꼴 로딩을 확인하고 1024×500으로 캡처한다. `?theme=dark`는 네이비. SVG 예비본은 검수한 PNG를 내장해 호스트 글꼴 대체를 피한다.

웹/PWA와 Android 설치 앱의 런처 리소스는 별개다. Android 리소스는 준비본이며 새 AAB/Play 업로드 완료를 의미하지 않는다.
