# 방문 이유와 코스 중심 1차 구현 — 2026-10-25

사용자가 승인한 방향: 오늘 어디 갈지 막막할 때 실제 방문 이유를 읽고 근처 장소·코스를 고른다. 구현 전후 root, 독립 GPT, 실제 Claude와 반론을 주고받았다. 이후 주요 제품·UI 결정에서도 이 방식을 유지한다.

## 화면
- 상단의 서로 다른 위계 메뉴를 없애고 하단 코스 / 맛집 / 저장 / 소식·생활로 통일. 기존 설정 푸터를 대체한다.
- 로고·내 주변·전국을 유지. 새 기본 화면은 코스이며 이전에 선택한 소식 화면은 복원한다. 소개 문구는 “오늘 어디 갈까, 날래!”.
- 코스 상단은 조건 한 줄. 관심 지역·동네 검색·지역 선택·두/세 곳·반경·장소 검색은 조건 창에 모은다. 공원·관광지 개별 목록도 유지한다.
- 처음 세 코스와 세 개 더 보기. 실제 조건을 충족하는 후보만 표시하며 여섯 개를 보장하지 않는다. 세 곳은 종류 중복·공원만 세 곳을 제외하고 직선 구간 합계 3km 이내다. 네 곳 자동 조합은 하지 않는다.
- 빈 제보 전용 탭을 만들지 않는다. 제보는 목록 끝과 설정에서 시작한다.

## 방문 제보·개인 기록
- 카탈로그에 없는 한 곳도 상호·공개 주소·출처로 제보 가능. 좌표는 운영자가 공개 자료로 확인한 뒤 승인 목록에 추가한다.
- 초안은 로컬 저장·삭제. 확인 후 메일 앱 열기 / 복사 / 텍스트 내려받기. 앱은 메일 접수를 주장하지 않으며 사용자가 직접 전송한다.
- 승인 JSON은 처음부터 빈 목록. 공개 동의, 관계 표시, 최근 방문월, 운영 확인과 공개 좌표를 검사한다. 검토는 실제 방문 인증이 아니다. 공개 내용은 네트워크 우선으로 갱신한다.
- 저장한 코스의 5점 별점·후기는 나만 보는 기록이다. 공개 평균·추천 인원·방문 인증으로 쓰지 않는다. 공개 게시판·공유 리뷰 서버는 보류한다.
- 코스 정체성은 실제 방문 순서가 있는 v2 ID. 자동 조합은 출발점이 바뀌어도 방향을 고정해 저장 상태가 뒤집히지 않는다. 직접 제보한 역방향 코스의 후기는 합치지 않는다.
- 제보 코스를 저장할 때 방문 이유·주의점·최근 방문월·광고 관계도 보존한다. 출발 좌표·발신자 메일은 저장하지 않는다.

## 실제 교차 검토에서 고친 문제
- GPT: 저장 화면이 마지막 생활정보 선택을 덮는 문제, 일부 조건 창의 닫기 갱신 누락, 저장 시 제보 관계 표시 소실.
- 제보 모듈 검토: 관계·대가 없음을 자동 선택하던 문제, 출처 입력 길이 불일치.
- Claude: 자동 코스 방향에 따라 저장 상태가 달라지는 문제, 저장 화면의 온라인 자료 의존, 기기 시계 변경 시 개인 메모 손실, 스토어 데이터 보안 초안의 옛 답변.
- root: 자동 갱신이 열린 조건 창을 지우는 문제, 최초 로드 중 다른 분류로 잠시 바뀌는 문제.

## 검증과 한계
- 자동 시험 102개 통과. 승인 목록 검사 통과(실제 게시물 0).
- 실제 로컬 브라우저 UI로 3→6개 표시, 두/세 곳 전환, 코스 저장·복원, 개인 별점 저장·삭제, 제보 초안 복원·삭제·메일 전 확인을 점검했다. 테스트 초안은 발송하지 않았다.
- 390×844와 320×740에서 가로 넘침 없음, 메뉴 각각 92px / 74.5px 너비와 최소 52px 높이 확인. 전체 시트 목록은 약 605px / 507px. 접힘·전체 전환과 목록 끝 접근을 확인했다.
- 실제 Android 키보드·제스처·현장 보행·영업·코스 만족도는 검증하지 않았다. 메뉴 정리나 테스트 통과만으로 추천 품질이 입증된 것은 아니다.
- Play 등록 문구는 저장소 초안만 수정했다. Play Console 데이터 보안 응답과 스토어 제출 완료를 뜻하지 않는다.

운영 절차는 [COMMUNITY_CONTENT_OPERATIONS.md](COMMUNITY_CONTENT_OPERATIONS.md)를 따른다.

## 실서비스 첫 진입 재검토 (v71)
- 새로 연 390px 화면의 기존 중간 시트에서는 지도 약440px·목록 약273px로 코스 하나만 읽혔다. GPT·Claude와 다시 토론해 코스·저장 탭은 목록 전체 높이로 열기로 했다. 지도 버튼은 임시로 접어 지도를 넓힌다.
- 새 코스 이용자의 기본은 전체, 기존 사용자가 직접 지정한 시트 높이는 시작 시 복원한다. 코스·저장 탭 진입과 지도 보기의 임시 높이 변경은 저장된 선호를 덮지 않는다.
