# 모바일 장소·데이트 화면 읽기 공간 개선

2026-10-25. 사용자가 중복 지역 줄 제거와 GPT·Claude 교차 검토를 요청했다.

## 반영한 변경

- 상단 내 주변·전국은 유지하고 중간의 전국·추가·편집·저장 줄을 제거했다.
- 관심 지역 선택·추가·관리·현재 동네 저장은 설정에서 제공한다. 설정을 닫은 뒤 관심 지역 창을 열거나 지도 지역을 선택해 모달이 겹치지 않는다.
- 두 곳 데이트는 한 번에 누르는 전용 버튼으로 유지한다. 다른 장소 종류는 선택 메뉴, 동네·이름 검색과 출처 안내는 검색·필터 창에서 제공한다.
- 모바일 맛집·놀거리 화면에서는 일반 탐험의 중복 분류 줄을 숨긴다. 동네 탐험은 일반 생활 화면을 열고 마지막으로 보던 생활 분류를 복원한다.
- 상단 메뉴의 선택 상태는 하나만 표시한다. 현재 동네 이름은 짧게 표시한다.
- 전체 높이의 놀거리 화면은 메뉴까지 함께 스크롤해 긴 코스의 주소·행동 버튼을 읽을 수 있다.
- 로고·날래 제목·소개 문구는 보존한다.

## 독립 검토

GPT 독립 검토는 지역 줄 제거와 설정 내 관심 지역 보존을 권고했다. 관련 높이 계산·ResizeObserver 참조 정리, 모달 전환 순서, 현재 조회 지역 표시, 단일 활성 상태도 확인해 반영했다. 중복 분류 줄을 숨기되 생활 기능 진입 경로와 마지막 분류를 보존하는 방향도 별도로 검토했다.

Claude에는 데스크톱 앱의 ‘날래 모바일 UI/UX 독립 교차검토’ 세션으로 같은 코드의 읽기 전용 검토를 의뢰했다. 구현·배포는 요청하지 않았다. 작성 시점에는 8토큰·작업 중 상태에서 응답이 지연돼 실제 검토 의견은 받지 못했다. 중단 및 모드 전환 시도는 자동 승인 검토에서 기존 작업 상태에 영향을 줄 수 있다는 이유로 거부됐고, 기존 검토를 실행 상태로 유지했다. Claude 검토가 끝났다고 주장하지 않는다.

## 확인 범위

- 자동 시험 76개 통과.
- 로컬 앱을 실제 브라우저의 390×844, 320×740 화면으로 열어 데이트 진입과 레이아웃 확인. 320px에서 문서 가로 폭 넘침 없음.
- 390px 전체 높이에서 데이트 결과 시작 위치는 화면 위 236px로 확인했다.
- 설정에서 현재 동네를 ‘집’으로 저장하고 다시 선택하면 설정 모달이 닫히는 동작을 확인했다. 테스트 저장은 로컬 미리보기 출처에만 적용된다.
- 검색·필터에서 검색어 입력·해제·완료, 생활 화면의 주유소 → 놀거리 → 동네 탐험 복귀 시 주유소 복원, 단일 활성 메뉴를 확인했다. 확인 중 브라우저 콘솔 오류 없음.
- 물리적 휴대폰의 터치 검증은 수행하지 않았다.
