## 관심 지역·최신성 구현 묶음 — 2026-10-21

이 절이 아래 이전 시안 메모의 A/B 분기·1시간 지연 기준보다 우선해요.

- 관심 지역은 시트 머리의 전국·저장 지역 칩과 관리 창으로 제공해요. 내장 경계 이름의 부분 일치 검색, 지도 선택·내 주변 결과 추가를 지원해요. 최대 5곳이며 같은 시·군·구 중복을 막아요. 이름은 20자까지, 집·직장·부모님 동네 또는 직접 입력할 수 있어요. 이름 변경·삭제·앞뒤 이동·시작 화면 지정/해제가 가능해요. 기본은 전국이며 마지막 선택은 복원하지 않아요. 데모 near는 시작 지역보다 우선해요.
- 저장 키 `nallae-favorites-v1`의 구조는 `{ "version": 1, "regions": [{ "code": "11440", "name": "집" }], "startCode": null }`예요. 배열 순서가 표시 순서이며 startCode는 저장된 지역 코드 또는 null이에요. 읽을 때 버전·배열·지역 코드·이름·중복·개수를 검증해요. 읽기/쓰기 모두 try/catch로 보호하고 쓰기 실패 시 안내 후 실행 중 메모리만 유지해요. 기존 화면 설정 키 `nallae-theme`는 system/light/dark 문자열이에요. 좌표·저장 지역을 전송하지 않아요.
- 상태 버튼은 지역 선택과 관계없이 보여요. 출처별 ok=false면 오류, ok=true이고 유효한 at가 30분 미만이면 정상, 30분 이상이거나 시각/정보 누락이면 지연이에요. 정상·지연은 마지막 성공 경과 시간을 표시해요. 오류 응답 at는 실패 시도 시각이므로 마지막 성공으로 표시하지 않아요. note는 이스케이프해서 상세에 표시해요.

- 분류는 전체 items에 있는 것만 표시하고 사라진 선택 분류는 전체로 돌아가요. 전국 라벨 충돌 여백을 가로 2px/세로 1px로 줄이고 재생 안내의 실제 사각형만 피하게 했어요. 기존처럼 안내 아래 전체 폭을 제외하지 않아요.

## 이전 구현 기록

- 브랜치: `design/stage-1`. A·B는 색 토큰과 이름 옆 표식색만 다르며 DOM·구성·간격은 동일하다.
- 검토 URL: `?demo&design=A&theme=light`, `?demo&design=B&theme=dark`. 기존 `near`, `open`, `debug`를 함께 사용할 수 있다.
- 테마 버튼은 시스템 → 라이트 → 다크 순환. URL 지정은 해당 진입의 검토값이고 버튼 선택은 localStorage에 저장한다.
- 일반 신호는 brand, 나머지는 urgency에 대응하는 의미 토큰을 사용한다. 값 누락은 추정 없이 구분 미제공. 표시 근거는 상세에 원문 그대로 출력한다.
- 수집 파일 요청 실패, 출처별 수집 실패, 1시간 넘은 갱신 지연을 구별한다. 지연 기준은 화면 표시 기준이며 안전 판단이 아니다.
- 기본 피드 정책 묶음은 정책 필터로 연결된다. 기존 지역 선택의 지도 대상 제한(onMap:false 제외)은 유지했다.

## Claude 5차 검토 반영 (1~4)

1. 마커마다 붙이던 말풍선을 고정 오버레이 하나로 분리했다. 점·파문은 지역 좌표에 남기고 말풍선만 안전 영역에 배치한다.
2. 상태의 물음표는 CSS `content:'?'`가 원인이었다. 글리프 대신 6px 원을 그린다. 정상=brand, 1시간 초과 지연=signal-urgent, 요청/출처 실패=signal-critical 순으로 실패를 우선한다. 상대 시각과 기존 실패 안내는 유지한다.
3. 전국 부제는 ‘최근 72시간 · 새 소식은 지도에서 먼저 반짝여요’로 변경했다. 지역 선택 시 기존 포함 지역 안내를 유지한다.
4. 재생 토스트는 안전 영역 맨 위에 고정한다. 토스트 z-index 900, 말풍선 850이며 말풍선 배치에서는 토스트 높이와 8px 간격을 제외한다.

### 말풍선 명세

- 동시에 DOM 한 개만 표시한다. `[위급/긴급 배지] 지역 · 제목` 한 줄이며, 지역·제목을 합친 텍스트에 말줄임을 적용한다. 본문은 목록/상세에서 읽는다. 배지는 기존 urgency 규칙을 따른다.
- 최대 폭은 화면 너비의 72%와 안전 영역 너비 중 작은 값이다. 배지 폭은 보존한다.
- 안전 영역: 상단 브랜드·지도 조작부의 실제 하단 +8px부터 모바일 시트 상단 −12px까지. 데스크톱은 시트 오른쪽 +16px, 지도 조작부 왼쪽 −12px 사이이며 하단 28px는 출처 표기를 위해 비운다. 좌우 화면 여백은 최소 12px다.
- 좌표 오른쪽/위쪽에 놓았을 때 넘치면 왼쪽/아래쪽으로 뒤집고, 최종 위치를 안전 영역에 제한한다. 지도 이동·확대, 창 크기, 상단/조작부/시트 크기, 재생 토스트 표시 변경 때 다시 계산한다.
- 위급은 4초 동안 교체하지 않는다. 그동안 들어온 말풍선 요청은 쌓지 않고 생략한다(점·파문·목록은 유지). 나머지는 다음 요청으로 즉시 덮어쓰며 마지막 표시 후 2.8초에 숨긴다.
