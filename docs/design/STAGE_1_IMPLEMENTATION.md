# 디자인 1단계 구현 검토 메모

- 브랜치: `design/stage-1`. A·B는 색 토큰과 이름 옆 표식색만 다르며 DOM·구성·간격은 동일하다.
- 검토 URL: `?demo&design=A&theme=light`, `?demo&design=B&theme=dark`. 기존 `near`, `open`, `debug`를 함께 사용할 수 있다.
- 테마 버튼은 시스템 → 라이트 → 다크 순환. URL 지정은 해당 진입의 검토값이고 버튼 선택은 localStorage에 저장한다.
- 일반 신호는 brand, 나머지는 urgency에 대응하는 의미 토큰을 사용한다. 값 누락은 추정 없이 구분 미제공. 표시 근거는 상세에 원문 그대로 출력한다.
- 수집 파일 요청 실패, 출처별 수집 실패, 1시간 넘은 갱신 지연을 구별한다. 지연 기준은 화면 표시 기준이며 안전 판단이 아니다.
- 기본 피드 정책 묶음은 정책 필터로 연결된다. 기존 지역 선택의 지도 대상 제한(onMap:false 제외)은 유지했다.

## 대비와 용량

WCAG 상대휘도 공식으로 본문·보조 글자·brand·위급·긴급·미제공 색을 패널/보조 표면과 대조했다. 선택 칩(brand/selection-fill), 주 버튼(on-brand/brand), 지도 위 상단 글자(text 및 text-muted/sea)도 포함했다.

| 시안 | 테마 | 검사한 조합의 최저 대비 |
|---|---|---|
| A | 라이트 | 5.10:1 |
| A | 다크 | 5.37:1 |
| B | 라이트 | 4.88:1 |
| B | 다크 | 5.75:1 |

토큰 hex 보정 없음. 꿀색은 장식 표식에만 사용한다. 행정 경계는 문자나 조작부가 아닌 지도 구획선이다.
앱 JS+CSS는 41,912바이트(데이터·vendor·폰트 제외)로 100KB 이하. 서비스워커는 `nallae-v5`이며 폰트 CSS를 셸에 포함했다.

## 검증과 Claude 검토

- `node --check web/app.js`, `node --check web/sw.js` 및 기존 파서 시험 5개 통과.
- 임시 DOM 모의 시험: 초기화, urgency 누락/일반/위급, 제목 중복 판별, id별 DOM 재사용·수정·삭제, 보류 항목과 스크롤 보존, 열린 상세, 정책 접기, 빈 상태 확인. 프레임워크나 시험 의존성은 추가하지 않았다.
- 실제 브라우저 검증과 스크린샷은 수행하지 않았다. Claude가 375×812 A·B/라이트·다크/전국·지역 8장과 긴 제목·위급 배지를 검토한다.
- 특히 키보드로 상세를 연 뒤 수집 데이터 변경, 아래로 읽는 중 새 소식 버튼, 정책 묶음 포커스, 시스템 테마 실시간 변경, 재생 도중 테마 변경, 모션 축소에서 지도 비행·파문 생략을 확인한다.
- 모바일 하단 시트의 글자 확대/긴 지역명과 필터 가로 스크롤, 말풍선의 지도 가장자리 잘림, 실제 폰트 로드 및 오프라인 재진입은 실기기 확인이 남아 있다.
- 데모와 실데이터의 urgency/urgencyBasis 제공은 Claude 작업과 병합 후 확인한다. 필드가 없으면 모든 항목이 구분 미제공으로 표시된다.

## Claude 4차 검토 반영 (1~7)

1. 테마를 해·달·모니터(자동) SVG 아이콘 하나로 변경했다. 현재 설정의 aria-label과 순환 설정은 유지했다. 정보도 SVG 아이콘, 데모는 작은 텍스트 태그로 변경했다. 버튼 터치는 44px, 보이는 배경은 38px이다.
2. 이름 옆 표식은 두 겹 파문과 중심점으로 변경했다. 이름 600, 슬로건 12px이며 시안별 signature 토큰을 따른다.
3. 카드 제목을 열림 여부와 관계없이 보존한다. 중복 판별로 제목을 ‘상세 소식’으로 바꾸던 분기를 제거했다. 상세는 기존 본문과 출처를 표시한다. 목록 밖 고정 개인정보 문구를 제거해 본문 공간을 확보했다. 개인정보처리방침은 상단 앱 정보 화면에서 접근한다.
4. 갱신 상태는 헤더 오른쪽 점+상대 시각으로 모았다. 실패·지연 안내는 보존한다. 재생 상태는 지도 위 작은 토스트로 옮겼다. 필터 아래와 카드 간격을 줄이고 제목을 16px/24px로 조정했다. 375 중간 시트에서 2.5~3건 목표의 실제 달성 여부는 Claude 재촬영으로 확인한다.
5. **원인:** urgency→의미 토큰 매핑 자체는 정상이다. 현재 데모에서 제주 위급 소식은 지도 대상 시간순 13번째(인덱스 12)라 `500+12×550=7,100ms` 후 재생된다. 촬영 도구의 전국 대기는 4,200ms여서 위급 점이 아직 나오지 않은 화면이었다. 추가로 기존 말풍선은 1.7초 후 표시되지만 다음 말풍선이 이전 마커 전체를 삭제해, 배지가 표시되기 전에 사라질 수 있었다. 일부 항목에만 말풍선을 붙이던 샘플링도 긴급 배지를 보장하지 않았다.
   - 최근 1시간/최대 20건 범위와 위급→긴급→나머지 재생 순서는 유지한다(동일 구분 안에서는 시간순). 점·파문·면 강조는 동일한 urgency 의미 토큰을 사용한다. 말풍선 수명·교체 규칙은 아래 5차 명세로 대체한다.
6. 미선택 칩에 surface-muted 면을 추가했다. 칩 아이콘은 20px, 터치는 44px 이상이다.
7. 메타 순서는 배지→분류→지역→시간이다. 지역은 본문색/600, 시간은 보조색/400, 분류는 16px 아이콘과 12px 라벨로 구분했다.

A·B는 같은 DOM·간격·조판을 사용하며 차이는 색 토큰뿐이다. 8번 지도 데이터와 scripts/는 수정하지 않았다. 외부 요청·의존성 추가·커밋·스크린샷 촬영은 수행하지 않았다.

### 이번 검증과 남은 위험

- `node --test "scripts/test/*.test.mjs"`: 5개 통과. app.js/sw.js 구문 검사 통과.
- Node VM으로 위급·긴급·일반·미제공의 신호 토큰, 위급 배지, 카드 제목 보존 분기, 재생 상태 ID 유일성을 확인했다. 기존 의미 색과 표면 토큰을 그대로 사용해 위 대비표의 색 조합을 유지한다.
- 실제 브라우저 검증은 미수행이다. Claude가 8장 재촬영하면서 목록 밀도, 긴 실패 상태와 제목 충돌, 확대 글자, 터치·키보드 조작을 확인해야 한다.
- 오래된 데모는 최근 1시간 재생 범위에서 제외되므로 촬영 시 데모 시각을 확인해야 한다.

## Claude 5차 검토 반영 (1~4)

1. 마커마다 붙이던 말풍선을 고정 오버레이 하나로 분리했다. 점·파문은 지역 좌표에 남기고 말풍선만 안전 영역에 배치한다.
2. 상태의 물음표는 CSS `content:'?'`가 원인이었다. 글리프 대신 6px 원을 그린다. 정상=brand, 1시간 초과 지연=signal-urgent, 요청/출처 실패=signal-critical 순으로 실패를 우선한다. 상대 시각과 기존 실패 안내는 유지한다.
3. 전국 부제는 ‘최근 72시간 · 새 소식은 지도에서 먼저 반짝여요’로 변경했다. 지역 선택 시 기존 포함 지역 안내를 유지한다.
4. 재생 토스트는 안전 영역 맨 위에 고정한다. 토스트 z-index 900, 말풍선 850이며 말풍선 배치에서는 토스트 높이와 8px 간격을 제외한다.

### 말풍선 명세

- 동시에 DOM 한 개만 표시한다. `[위급/긴급 배지] 지역 · 제목` 한 줄이며, 지역·제목을 합친 텍스트에 말줄임을 적용한다. 본문은 목록/상세에서 읽는다. 배지는 기존 urgency 규칙을 따른다.
- 최대 폭은 화면 너비의 72%와 안전 영역 너비 중 작은 값이다. 배지 폭은 보존한다.
- 안전 영역: 상단 브랜드·지도 조작부의 실제 하단 +8px부터 모바일 시트 상단 −12px까지. 데스크톱은 시트 오른쪽 +16px, 지도 조작부 왼쪽 −12px 사이이며 하단 28px는 출처 표기를 위해 비운다. 좌우 화면 여백은 최소 12px다.
- 좌표 오른쪽/위쪽에 놓았을 때 넘치면 왼쪽/아래쪽으로 뒤집고, 최종 위치를 안전 영역에 제한한다. 지도 이동·확대, 창 크기, 상단/조작부/시트 크기, 재생 토스트 표시 변경 때 다시 계산한다.
- 위급은 4초 동안 교체하지 않는다. 그동안 들어온 말풍선 요청은 쌓지 않고 생략한다(점·파문·목록은 유지). 나머지는 다음 요청으로 즉시 덮어쓰며 마지막 표시 후 2.8초에 숨긴다.
- 공간이 부족하면 말풍선을 숨겨 조작부와 시트를 보호한다. 이 경우 위급 4초 가시성도 보장할 수 없으므로 목록 배지가 정보를 보완한다.
- 말풍선 자체는 애니메이션이 없다. 기존 reduced-motion의 지도 비행·파문 생략, 44px 터치 크기를 유지한다. A·B의 구성·배치·타이밍은 같고 색 토큰만 다르다.

### 검증 및 남은 위험

- `node --test "scripts/test/*.test.mjs"` 5개 통과, app.js/sw.js 구문 검사와 `git diff --check` 통과. Node VM으로 위급 4초 보호·다음 요청 덮어쓰기·2.8초 만료를 확인했다.
- 외부 요청·프레임워크·의존성 추가 및 scripts/ 수정 없음. 기존 텍스트/의미색 토큰 조합을 유지해 위 대비표(최저 4.88:1)를 적용한다.
- 실제 브라우저 재촬영은 Claude 담당이다. 특히 375px 긴 제목, 위급 4초 유지, 시트 접기/펼치기, 글자 확대, 데스크톱 안전 영역을 확인해야 한다.
- 안전 영역으로 옮겨진 말풍선은 점과 떨어질 수 있다. 위치 해석은 말풍선 지역명과 원래 좌표의 점을 함께 사용한다. 보호 중 생략된 소식은 목록에서 읽는다.
- 커밋과 스크린샷 촬영은 수행하지 않았다. 작업 시작 전에 변경돼 있던 PNG 8개는 수정하지 않았다.
