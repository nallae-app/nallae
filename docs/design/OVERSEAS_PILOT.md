# 일본·중국 여행 코스 시작판 — 2026-11-14

## 제품 방향과 제공 범위

사용자 승인: 처음 지도에서는 현지어 지명이 보이고, 확대하면 한국어로 도시를 이해하고 실제 코스를 고를 수 있게 한다. 오사카·교토·상하이 3도시, 공개 사실을 바탕으로 묶은 두 장소 코스 6개로 시작한다. 국내 코스·맛집·저장·소식·생활과 부캉이를 유지한다. 중국·일본 전역의 코스 제공이나 모든 글자의 번역을 약속하지 않는다.

- 저배율: 로컬 해안선과 中国 / 日本 / 大阪·京都 / 上海. 가까운 오사카·교토는 좌표를 옮기지 않고 묶었다가 확대한다.
- 확대: 제공 도시의 한글·현지어 병기. 외부 벡터 지도에서 한국어가 비어 있으면 현지어로 대체한다.
- ‘국내 코스 / 일본·중국 여행’ 전환과 도시 선택. ‘전국’은 기존 한국 전국으로 돌아간다.
- 방문 이유·두 장소의 조합 이유·공식 안내·현지어 주소를 제공한다. 영업시간·현재 개방·입구·도보시간·방문 수·평점을 창작하지 않는다.
- 일본: API 키 없는 Google Maps 공식 URL로 공개 이름·주소 기반 도보 경로를 연다. 중국: 현지어 이름·주소 복사와 공식 안내, 선택적인 Google 장소 검색. 중국 현지 접근성·턴바이턴 안내를 보장하지 않는다.
- 해외 저장은 `jippi-overseas-plans-v1`에 따로 보관하고 저장 화면 ‘여행’ 탭에서 꺼낸다. 기존 국내 저장/후기/‘이번엔 여기’ 키에 혼입하지 않는다. 저장 오류 시 변경 전 상태를 보존하고 카탈로그에서 빠진 저장 식별번호도 삭제하지 않는다.

## 지도 출처와 이용 조건

- 로컬 육지 윤곽: Natural Earth `ne_50m_land.geojson`을 mapshaper 12% keep-shapes / precision0.001로 간략화했다. 국경이 아닌 물리적 육지 윤곽이다. [public domain 이용 조건](https://www.naturalearthdata.com/about/terms-of-use/).
- 상세지도: [OpenFreeMap 공식 Leaflet 연결](https://openfreemap.org/quick_start/), MapLibre GL JS5.15.0 + 공식 Leaflet adapter0.1.4를 vendor에 내장했다. 라이선스 파일도 포함한다.
- [OFM 이용 조건](https://openfreemap.org/tos/)의 보장 없는 제공 및 오프라인 다운로드 조건을 확인했다. 외부 타일은 서비스 워커 일괄 캐시하지 않는다. 초기 상세지도 요청 전에 IP·보는 지도 영역 전송을 고지한다.
- 첫 지도·코스·저장은 외부 지도 없이도 사용한다. 사용자가 상세지도를 켜야 외부 요청을 시작하고, 끄거나 국내 화면으로 돌아오면 요청과 GL을 중단한다. 실패하면 로컬 도시/코스/해안선으로 돌아간다.
- [OFM 개인정보 정책](https://openfreemap.org/privacy/)상 오류 IP/URL7일, 보안 사건의 IP 최대30일과 [CDN 정책](https://www.cloudflare.com/privacypolicy/)을 고지했다. 지도 접속 식별정보는 선택적·비일시 처리 신고로 준비한다. 공개 도시 조회를 이용자의 실제 위치 수집으로 단정하지 않는다. 기존 GPS 주유소 위치 신고는 별개다.
- 저배율 물 이름·외부 국경선은 표시하지 않는다. 기존 한국 행정구역·독도 한글 표시를 유지하고, 벡터 도시 라벨은 준비된 도시 주변으로 제한한다.
- 장소 내용은 각 카드에 운영기관/관광기관 출처 링크를 제공하고, 대표 좌표는 [Wikidata CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)다. 공식 기사/사진/리뷰를 수집·복제하지 않았다.
- Amap URI는 좌표 없이 중국어 검색이 가능하지만 [약관3.1](https://developer.amap.com/pages/terms/)의 제품 이용 허가 조건이 명확하지 않아 추가하지 않았다.

## 실제 삼단 검토

Codex가 통합·화면 검수를 하고, 독립 GPT가 지도 모듈·데이터·제품 회귀를 검토했으며, 실제 Claude Code가 설명 검토 후 파일을 읽어 코드 검토와 재검토에 응답했다. 설명만 검토한 단계와 실제 파일 검토를 구분했다.

반영한 핵심 반론:

1. 해외 자료를 국내 코스 인덱스 로드와 분리하고 국내 갱신이 해외 UI·펼친 상세·읽던 위치를 덮지 않게 했다.
2. 늦은 GPS 응답이 새 여행 화면을 덮지 않게 요청 ID를 갱신했다.
3. 국내로 돌아오면 벡터 요청을 중단하고 국가 라벨은 고배율에 숨긴다.
4. 준비 후 단일 타일 오류는 지도 전체를 지우지 않는다. 초기 오류·시간 초과·WebGL 손실은 로컬 대체로 복구한다. 정상 adapter 해제를 중복 호출하지 않고 예외 때만 비상 해제한다.
5. 미확인 저장 ID도 개수를 알리고 보존한다. 마지막 저장 해제 후 초점은 여행 탭으로 돌아간다.
6. 도시 선택과 코스 맞춤에 헤더·시트·마커 크기를 반영한다. 출처 표시도 모바일 시트 위에 놓는다.

최종 검증과 배포 결과는 출시 체크리스트 최신 항목과 로컬 검수 자료를 우선한다.
