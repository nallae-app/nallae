# 브랜드·계정 정리 현황

2026-10-22 확인. 사용자 요청: 외부에는 가능한 한 브랜드 이름과 nallae.app@gmail.com만 표시. 기존 로그인·키·서명을 일괄 교체하지 않고 공개 표기와 소유권 이전을 구분한다.

## 즉시 정리 가능한 공개 표기

| 대상 | 확인 결과 / 조치 |
|---|---|
| 웹앱 문의·개인정보처리방침 | 이미 nallae.app@gmail.com. 운영자는 날래 개발자 |
| 스토어 문안 | 이미 브랜드 이메일 사용 |
| 공개 웹 주소·저장소 주소 | 이미 조직 nallae-app 사용 |
| 공개 개발 문서 | 기존 개인 패키지 문자열을 일반 안내로 정리. 이전 식별자는 실제 연결 파일과 AAB로 확인하도록 함 |
| Git 작성자 | GitHub noreply 사용 확인. 기존 로컬 작성자 규칙 및 과거 이력 유지 |
| Play 개발자 표시명·공개 개발자 이메일·앱 지원 이메일 | 브랜드 값으로 설정 가능. 현재 Console은 연결된 브라우저에서 접근할 수 없어 실제 저장값은 미확인·미변경. 이메일 인증이 필요할 수 있음 |

## 계정 이전 없이 유지 가능한 내부 항목

- Google 로그인과 공개 개발자 연락처는 별개. 기존 소유자 로그인을 유지해도 공개 연락처는 브랜드 이메일로 설정할 수 있다.
- API 발급 계정·GitHub 인증 계정은 웹의 공개 연락처와 별개. 서비스 중단을 유발하는 키 재발급·권한 삭제는 이번에 하지 않음.
- 브랜드 계정의 Console 사용자 초대는 소유권 이전과 별개이며, 권한 확대를 수반하므로 실제 권한을 확인한 뒤 진행한다. 초대 메일은 이번에 보내지 않음.
- 현재 Console 소유자, 브랜드 계정의 개발자 계정 보유 여부와 신원 확인 상태는 미확인. 예전 기록만으로 현재 상태를 단정하지 않는다.

## 재빌드가 필요한 패키지 이름

### 2026-10-22 후속 완료
- 사용자 Console에서 `app.nallae` 사용 가능 확인 후 해당 이름으로 앱 생성. 이 패키지를 최종 확정함.
- 공식 PWABuilder로 새 AAB/APK 및 전체 소스를 생성. 새 패키지용 업로드 서명 키는 브랜드 명의 `NALLAE Developer`로 생성해 Git 제외 로컬 폴더에 저장. 기존 키를 덮어쓰거나 이전 패키지의 업데이트로 사용하지 않음.
- 로컬 결과: `android/app-nallae-20261022/package/`. 업로드할 파일은 `날래 - 우리 동네 소식.aab`. 서명 키·비밀번호·빌드 ZIP·접근 영수증은 공개하지 않음.
- AAB 내부 protobuf Manifest의 package app.nallae, version 1.0.0/code 1 확인. 빌드 Manifest target SDK 36 / min SDK 24 확인. 456개 서명 대상 파일의 SHA-256, 서명 Manifest 해시 및 CMS 서명 수학 검증, 인증서와 assetlinks 지문 일치 확인.
- 루트 `assetlinks.json`에 새 패키지와 인증서 연결을 추가하고 배포 성공·공개 반영 확인. 기존 연결은 기존 설치본 보존을 위해 유지.
- 남음: Play 업로드·Play 앱 서명 인증서 지문 추가·실제 Android 기기에서 주소창 제거 및 기능 검증. Google 계정 소유권 이전은 진행하지 않음.

아래는 재빌드 전 감사 시점의 기록이다.

- 루트 사이트 `.well-known/assetlinks.json`에서 기존 개인 식별자가 남은 Android 패키지 연결을 확인했다.
- 로컬에는 android/ 및 AAB가 없어 내부 applicationId와 서명 인증서를 대조할 수 없다.
- 후보 `app.nallae`는 예시이며 사용 가능 여부·도메인 소유권을 확인한 것이 아니다. Gmail 주소를 만들었다고 같은 도메인을 소유하는 것은 아니다.
- Play에 이미 패키지가 등록되었다면 이름을 바꿀 수 없다. 새 식별자를 쓰려면 별도 앱 등록과 맞는 AAB가 필요하다. 미등록이면 새 식별자로 빌드한 뒤 등록 가능 여부를 확인한다.
- 변경 시 applicationId/Manifest/TWA 빌드 설정 → 서명된 AAB → 루트 assetlinks 대상 패키지·실제 인증서 지문 → Console 등록을 일치시켜야 한다.
- 연결 파일만 먼저 바꾸면 기존 TWA 검증이 깨질 수 있어 이번에는 유지했다. 로그인 계정 변경이나 앱 소유권 이전으로 패키지 이름이 바뀌지는 않는다.

## 대기·심사가 있는 절차

| 절차 | 공식 안내 | 현재 조치 |
|---|---|---|
| 비수익 개인/조직 개발자 계정 소유자 변경 | 7일 보안 대기 후 새 소유자의 결제 프로필·신원 확인 등. 미해결 인증이 있거나 새 계정이 별도 Play Console 소유자면 제한 가능 | 미신청 |
| 별도 개발자 계정으로 앱 이전 | 양쪽 계정 등록·활성화 필요. 지원팀은 이전 요청에 영업일 2일 이내 검토·회신 안내. 전체 완료 기한 보장은 아님 | 미신청 |
| 신규 개인 계정 앱 출시 전 테스트 | 최소 12명, 연속 14일 비공개 테스트 후 프로덕션 액세스 신청 | 계정 이전과 별개 |

개인 개발자 계정은 별명과 별개로 법적 이름·국가·개발자 이메일이 공개될 수 있다. 브랜드 이메일로 바꿔도 법적 이름 공개 요건을 없애지는 않는다.
