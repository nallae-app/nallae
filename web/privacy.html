개인정보처리방침

시행일: 2026년 11월 1일

‘날래’(이하 “앱”)는 회원가입이나 로그인 없이 쓰는 지역 소식 지도입니다. 앱은 이용자를 알아볼 수 있는 개인정보를 수집하지 않습니다.

1. 수집하는 개인정보

없습니다. 이름, 연락처, 계정, 광고 식별자 등 어떤 개인정보도 받지 않으며, 분석 도구나 광고를 쓰지 않습니다.

2. 위치정보

  • ‘내 주변’ 버튼을 눌렀을 때만 기기에 위치 권한을 요청합니다.
  • 받은 좌표는 기기 안에서 내가 있는 시·군·구를 찾는 데만 씁니다.
  • 좌표와 판별 결과는 서버로 보내지 않고, 저장하지 않으며, 다른 곳에 제공하지 않습니다. 앱을 닫으면 사라집니다.
  • 위치 권한을 주지 않아도 지도에서 동네를 직접 눌러 같은 기능을 쓸 수 있습니다.

관심 지역과 화면 설정은 이 기기 안(브라우저 저장소)에만 저장되고 서버로 보내지 않아요. 앱 데이터를 지우면 함께 지워져요.

3. 자동으로 남는 정보

앱 파일과 소식 파일은 GitHub Pages에서 내려받습니다. 이 과정에서 GitHub가 보안과 서비스 운영을 위해 접속 기록(IP 주소 등)을 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고해 주세요. 운영자는 이 기록을 받거나 보관하지 않습니다.

4. 외부 링크

‘원문 보기’를 누르면 언론사나 기관의 사이트로 이동합니다. 그곳에서는 해당 사이트의 개인정보 처리방침이 적용됩니다.

5. 아동의 개인정보

앱은 누구의 개인정보도 수집하지 않으므로 만 14세 미만 아동의 개인정보도 수집하지 않습니다.
