개인정보처리방침

시행일: 2026년 11월 1일

‘날래’(이하 “앱”)는 회원가입이나 로그인 없이 쓰는 지역 소식 지도입니다. 회원정보·연락처·광고 식별자를 받지 않으며, 주변 주유소 조회를 선택한 경우 아래와 같이 위치 좌표를 일시 처리합니다.

1. 수집하는 개인정보

이름, 연락처, 계정, 광고 식별자를 받지 않으며 분석 도구나 광고를 쓰지 않습니다. 위치 기반 주유소 조회에서는 선택한 좌표·유종·반경을 조회 목적으로 일시 처리하며 앱 자체의 위치 로그나 기기 저장소에 기록하지 않습니다.

2. 위치정보

  • ‘내 주변’ 버튼을 눌렀을 때만 기기에 위치 권한을 요청합니다.
  • 받은 좌표는 기기 안에서 내가 있는 시·군·구와 주변 장소의 거리를 찾는 데 씁니다.
  • 동네 소식·놀거리의 내 주변 검색은 좌표와 판별 결과를 서버로 보내지 않습니다. 앱을 닫으면 사라집니다.
  • 주유소 화면에서 ‘내 위치로 주유소 조회’를 직접 누르면 위치 좌표·유종·반경을 날래 조회 서버(Vercel)와 오피넷(한국석유공사)에 전달합니다. 조회에만 사용하며 앱의 위치 로그나 기기 저장소에 남기지 않습니다. 지도에서 동네를 직접 골랐으면 그 동네 대표 지점으로 조회합니다. 지도 서비스·호스팅 제공자는 자체 정책에 따라 접속기록 등을 처리할 수 있습니다.
  • 길찾기에서 ‘내 위치를 출발점으로’를 직접 선택하고 카카오맵 길찾기 링크를 누르면 출발 좌표와 목적지가 카카오맵에 전달됩니다. 지도에서 출발점을 직접 고르거나 카카오맵에서 출발지를 선택할 수도 있습니다.
  • 위치 권한을 주지 않아도 지도에서 동네를 직접 눌러 같은 기능을 쓸 수 있습니다.

관심 지역, 가보고 싶은 식당의 식별번호, 저장한 놀거리·코스의 공개 장소 정보, 화면 설정은 이 기기 안(브라우저 저장소)에만 저장되고 서버로 보내지 않아요. 코스를 저장할 때 내 위치 좌표는 포함하지 않아요. 앱 데이터를 지우면 함께 지워져요.

3. 자동으로 남는 정보

앱 파일과 소식 파일은 GitHub Pages에서 내려받습니다. 이 과정에서 GitHub가 보안과 서비스 운영을 위해 접속 기록(IP 주소 등)을 처리할 수 있습니다. 주유소 조회 서버를 이용할 때는 Vercel도 보안·서비스 운영 목적의 접속기록을 처리할 수 있습니다. GitHub 개인정보 처리방침 · Vercel 개인정보 처리방침. 앱은 분석·광고 목적의 위치 기록을 만들지 않습니다.

4. 외부 링크

‘원문 보기’를 누르면 언론사나 기관의 사이트로 이동합니다. 그곳에서는 해당 사이트의 개인정보 처리방침이 적용됩니다.
